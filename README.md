# Sale Price Update Assistant

Odoo module for bulk sale price updates with:

- **Category tree panel** (like the Inventory stock view) for filtering products
- **Multi-pricelist support** — update several pricelists in one shot
- **% increase per product or global** — with live preview of old vs. new price
- **Price history** — permanent log of every price change with user, date, %, and previous price
- **Server action** — accessible from the product list view (variants and templates)
- Compatible with **Odoo 17, 18, 19** — Community and Enterprise

## Installation

1. Copy the `sale_price_update` folder into your Odoo addons path.
2. Update the app list and install **Sale Price Update Assistant**.

## Usage

- **Ventas → Catálogo → Actualizar Precios** — open the wizard from the menu.
- Select products in the product list → **Action → Actualizar Precios de Venta**.
